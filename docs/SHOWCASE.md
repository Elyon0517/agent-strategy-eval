# Reproduce the showcase

Verified locally on 2026-10-24 with Python 3.12 / Node 24 as applicable and Chromium headless.
Commands run from the repository root. Browser screenshots use synthetic example data.

## Commands

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
pytest -q
ruff check .
mypy
python examples/showcase.py
# Optional browser tooling, kept outside the SDK's runtime dependencies:
uv run --with playwright playwright install chromium
uv run --with playwright python examples/test_showcase.py
```

## What was verified

- 10 SDK tests passed; Ruff and mypy passed.
- The generator evaluates the actual five baselines against `examples/fixtures.json` and
  emits 15 measurements, aggregate rates and the full machine-readable report.
- Browser acceptance passed: all 15 rows render; filtering `profile` shows five rows;
  the personalized row exposes `Answer in Spanish`; JSON totals and rates match the SDK.
- `docs/screenshots/strategy-scorecard.png` is regenerated by that browser test.
- Synthetic substring checks are not semantic task-success scores. No LLM or paid API was used.
  Measured latency is in JSON, and is intentionally not presented as a stable benchmark.

## Reading the images

Screenshots are committed so GitHub renders them immediately. They are generated by the
browser acceptance scripts, not hand-composed mockups. Re-running a capture can change
layout, animation timing and measured latency slightly. Browser traces on test failure
are local debugging artifacts and are not committed.
